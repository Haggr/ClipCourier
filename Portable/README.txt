ClipCourier 0.1.0 — Windows x64 portable build

Requires Windows 10 or 11 with .NET Framework 4.8.

Run ClipCourier.exe. Open its notification-area icon menu and choose Settings to add destination files. Select text in an app, press Ctrl+Alt+J, choose one or more destinations, then append. Add several destinations at once; each is labeled with its file name without the extension. Entries are separated by a single line break.

Settings and logs are stored in %LOCALAPPDATA%\ClipCourier. This build is unsigned, so Windows SmartScreen may show a reputation warning.

See the project README for source, privacy details, and known limitations.
